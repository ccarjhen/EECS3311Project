# EECS 3311 Grocery Project

## Java and Maven

This project targets Java 25. Use a Java 25 JDK and Maven 3.9 or newer to build
and test it. On macOS, select an installed Java 25 JDK with:

```sh
export JAVA_HOME=$(/usr/libexec/java_home -v 25)
```

From this directory, compile the application and tests and run the test suite:

```sh
mvn clean test
```
